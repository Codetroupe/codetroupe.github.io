一键项目设置

Quick Setup 会扫描项目、选择需要的配置，并一次性写入 Gradle，不需要手动编辑多个文件。

build.gradle.kts - Quick Setup 生成
// Quick Setup 应用：渠道、SDK、R8 和 ResGuard

android {
    flavorDimensions += "channel"
    productFlavors {
        create("google") { dimension = "channel" }
        create("huawei") { dimension = "channel" }
    }
    buildTypes { release { isMinifyEnabled = true; isShrinkResources = true } }
}

dependencies {
    implementation(platform("com.google.firebase:firebase-bom:33.7.0"))
    implementation("com.google.firebase:firebase-analytics")
    implementation("com.google.firebase:firebase-crashlytics")
    implementation("com.squareup.retrofit2:retrofit:2.11.0")
}
