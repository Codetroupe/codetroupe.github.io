开始使用 ADB Pro

从安装插件到第一次安装 AAB，这个指南会带你走完开始使用 ADB Pro 所需的全部基础步骤。

5 个步骤完成上手

按照这些步骤安装、配置，并开始在 Android 项目中使用 ADB Pro。

安装插件

打开 JetBrains IDE，进入 Settings > Plugins > Marketplace。搜索 ADB Pro 并点击 Install。按提示重启 IDE。也可以直接从 plugins.jetbrains.com 打开插件页面。

激活许可证

首次启动会自动开始 30 天免费试用，无需信用卡。付费许可证可以在 Settings > Tools > ADB Pro > License 中查看。所有许可证校验都由 JetBrains Marketplace 基础设施处理。

打开 Android 项目

在 IntelliJ IDEA 或 Android Studio 中打开任意 Android 项目。ADB Pro 会自动识别 Gradle 配置、签名配置和构建变体。IDE 右侧边栏会出现 ADB Pro 工具窗口。

第一次安装 AAB

在终端执行 ./gradlew bundleRelease。打开 ADB Pro 工具窗口中的 AAB Tools 标签页，点击 Quick Install AAB 或选择检测到的 .aab 文件。选择已连接设备后执行安装即可。

继续探索功能

ADB Pro 工具窗口中的每个标签页都是独立工具。最快的设置方式是使用 Quick Setup，它会分析项目并一次性配置依赖、R8 混淆规则、资源保护、构建性能优化和 CI/CD 流水线。也可以按需使用 R8 Assistant、Release Readiness、Bundle Inspector、Lint Tools 等单独能力。

推荐发布工作流

按这个流程执行，可以让发版过程更清晰，也更容易在发布前发现风险。

release-workflow.sh
# 0. 可选：新项目先用 Quick Setup 一键配置
# 打开 Quick Setup 标签页 -> 选择 SDK 栈
# 点击 Apply All，一次性配置依赖、R8 规则、Res Guard 和 CI/CD

# 1. 构建 release bundle
./gradlew bundleRelease

# 2. 检查 bundle 体积和内容
# 打开 Bundle Inspector -> 加载 .aab
# 查看体积分布、资源审计和冗余扫描

# 3. 执行 lint 检查
# 打开 Lint Tools -> Run Analysis
# 查看严重级别分布和修复建议

# 4. 生成并审查 R8 / ProGuard 规则
# 打开 R8 Assistant -> Scan Dependencies
# 应用推荐规则，选择混淆字典

# 5. 运行发布检查清单
# 打开 Release Readiness -> Run All Checks
# 确保 debuggable、API keys、签名等 13 项检查通过

# 6. 安装到设备并测试
# 打开 AAB Tools -> Quick Install AAB
# 选择设备 -> Install -> smoke test

# 7. 发布
# 确认后上传到 Google Play Console

常见问题

开始使用 ADB Pro 时经常会遇到的问题。

支持哪些 IDE？

ADB Pro 支持 IntelliJ IDEA 2022.3+ 和 Android Studio Giraffe+。IntelliJ IDEA Community 和 Ultimate 都支持。

支持 Kotlin DSL 吗？

支持。Groovy 的 build.gradle 和 Kotlin DSL 的 build.gradle.kts 都可以识别和解析。

需要单独安装 bundletool 吗？

不需要。ADB Pro 会自动下载和管理 bundletool，不需要你额外安装外部工具。

设置保存在哪里？

所有设置都会通过 IntelliJ 持久化框架保存在本地。密码和签名密钥等敏感数据会使用 操作系统凭据存储，例如 macOS Keychain、Windows Credential Manager 或 Linux Secret Service。

我的源码会被上传吗？

不会。 ADB Pro 在本机运行，不包含遥测、数据收集或额外网络调用。源码、构建产物和项目配置不会离开本地环境。
