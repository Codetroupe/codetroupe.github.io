开始使用 ADB Pro

从安装插件到第一次安装 AAB，这个页面帮你快速跑通 ADB Pro 的核心流程。

5 个步骤完成基础配置

安装、授权、打开 Android 项目，然后从 AAB Tools 开始体验完整工作流。

安装插件

在 Android Studio 或 IntelliJ IDEA 中打开 Settings > Plugins > Marketplace，搜索 ADB Pro 并安装。也可以从 JetBrains Marketplace 打开插件页面。

启用试用或订阅

首次使用可开始 30 天试用。购买、订阅和许可证校验都由 JetBrains Marketplace 处理，价格页会跳转到 JetBrains 官方购买页面。

打开 Android 项目

打开任意 Gradle Android 项目。ADB Pro 会识别构建变体、签名配置和常见输出目录，并在 IDE 工具窗口中显示功能入口。

第一次安装 AAB

执行 ./gradlew bundleRelease 后进入 AAB Tools。选择生成的 AAB、签名配置和目标设备，然后执行安装。多设备 smoke test 可以使用 Universal APK 批量安装。

继续检查发版风险

使用 Release Readiness 检查 debuggable、签名、R8、API Key、targetSdk、versionCode 和 16 KB page-size；使用 Res Guard 配置资源混淆。

准备试用 ADB Pro？

先跑通 AAB 安装和发版检查，再逐步把 R8、资源混淆、CI/CD 接入流程。
