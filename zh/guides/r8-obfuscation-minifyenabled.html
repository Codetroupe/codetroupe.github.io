Android Release 构建中的 R8 混淆与 minifyEnabled 说明

解释 minifyEnabled 做了什么、R8 如何压缩优化和混淆代码，以及 ProGuard 规则在现代 Android 构建中的作用。

约 11 分钟

快速结论：minifyEnabled true 会为 release 变体启用 R8，但安全发版还需要 keep 规则、mapping 保存、资源压缩检查和运行验证。

开发者常问的问题

  • Android 中 minifyEnabled true 是什么？
  • minifyEnabled 是否等于启用 R8 混淆？
  • R8、ProGuard rules、shrinkResources 和 mapping.txt 有什么区别？
  • 如何确认 R8 对 release 构建是安全的？

核心结论

minifyEnabled true 是开启 R8 的入口，但它不是完整混淆治理。你还需要规则、验证和回溯能力。

R8 做什么

R8 会移除未使用代码、优化字节码并重命名符号。它能减少包体积，也可能暴露 keep 规则不足的问题。

配置要点

release 构建中要配合 proguardFiles、consumer rules、mapping 归档和必要的 shrinkResources 检查。
