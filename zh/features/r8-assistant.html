混淆诊断

R8 Assistant

辅助配置 R8 / ProGuard 规则、扫描反射风险、分析 mapping，并处理混淆后的崩溃堆栈。

解决什么问题

R8 混淆能减小体积并保护代码，但 keep 规则不足会导致反射、序列化、Room、Gson、Parcelable 或第三方 SDK 在 release 环境崩溃。

典型工作流

  • 扫描项目中常见反射、序列化、数据库实体和 SDK 模式。
  • 生成或补充 R8 / ProGuard keep 规则建议。
  • 分析 mapping.txt，验证类名、方法名和字典输出是否符合预期。
  • 对混淆后的 stack trace 做还原，帮助定位线上崩溃。

适合的使用场景

  • 首次开启 minifyEnabled true。
  • 排查 release 包才出现的反射或序列化崩溃。
  • 配置 ProGuard obfuscation dictionary、class dictionary 或 package dictionary。
