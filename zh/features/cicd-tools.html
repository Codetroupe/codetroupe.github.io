CI/CD Tools

根据 Android 项目配置生成 GitHub Actions、GitLab CI 或 Jenkins 发布流水线。

解决什么问题

Android CI/CD 需要正确处理 JDK、Gradle cache、签名密钥、构建任务、产物上传、mapping 保存和发版检查。手写脚本容易遗漏细节。

典型工作流

  • 扫描项目模块、Gradle wrapper、构建任务和签名需求。
  • 选择目标平台并生成对应 YAML 或 pipeline 配置。
  • 把 secret、keystore、产物路径和 release 检查步骤拆清楚。
  • 让本地 IDE 构建流程和 CI 构建流程保持一致。

适合的使用场景

  • 为 Android 项目快速建立可复用的 CI 构建。
  • 把 APK/AAB、mapping、测试报告作为 CI artifact 保存。
  • 统一团队本地发版和自动化发版步骤。
