功能详情

先在上方预览界面，再打开你需要的具体工作流页面。

Start

项目概览和发版流程快捷入口。

Dashboard

项目元数据、快捷操作、健康状态和最近活动。

打开开始使用 →

Build / Package

构建、检查、签名并安装 Android 发版产物。

Build Tools

Gradle 执行、变体管理、批量构建、产物定位和构建历史。

查看详情 →

AAB Tools

AAB 转换、APKS 安装、签名、选中设备批量安装和远程 bundle。

查看详情 →

Bundle Inspector

AAB 体积、模块、manifest、资源、native libraries 和差异对比。

查看详情 →

Signing Tools

APK 签名、zipalign、证书验证和 keystore 管理。

查看详情 →

Release

发布前发现风险，避免把问题带到线上。

Release Readiness

检查签名、minification、SDK、native 兼容性和安全风险。

查看详情 →

Lint Tools

Android Lint 执行、结果解析、严重级别过滤和 baseline。

查看详情 →

Dependency Health

依赖树、冲突、重复依赖、降级和 version catalog 健康状态。

查看详情 →

Diagnose

诊断 R8、ProGuard、mapping、反射和混淆后的崩溃。

R8 Assistant

规则建议、反射扫描、mapping 分析、stack trace 和混淆字典。

查看详情 →

Optimize

优化构建速度、包体积和资源保护。

Build Performance

Gradle 任务分析、构建历史、健康检查和优化建议。

查看详情 →

Resource Obfuscation

AabResGuard 配置、白名单、Gradle 注入和执行。

查看详情 →

CI/CD

根据 Android 项目结构生成发布流水线。

CI/CD Tools

为 Android 构建生成 GitHub Actions、GitLab CI 和 Jenkins 配置。

查看详情 →

Setup

一次性引导 Android 项目完成基础配置。

Quick Setup

项目扫描、配置选择、Gradle 预览、应用和撤销。

查看详情 →

Web & Logs

IDE 内的 Android 开发资源导航和本地操作日志。

Web Navigation

Android 开发栈、应用商店、后端服务、分析工具和资源快捷入口。

打开资源导航 →

Logs

本地操作记录。日志不会自动上传，仅用于回顾工作流步骤。
