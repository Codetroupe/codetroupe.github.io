FAQ

发布 Android 应用需要哪些工具？

大多数 Android 应用需要 Android Studio、Kotlin 或 Java、Gradle、签名配置、发布测试、崩溃监控、分析工具，以及至少一个发布渠道，例如 Google Play Console。

独立 Android 应用适合什么技术栈？

实用起点是 Android Studio、Kotlin、Jetpack Compose、Material 3、Room 或 DataStore、Firebase 或 Supabase、Crashlytics 或 Sentry、GitHub Actions 和 Google Play Console。

Firebase 还是 Supabase？

Firebase 更移动优先，适合 Crashlytics、Analytics、Cloud Messaging 和 App Distribution。Supabase 适合需要 Postgres、SQL、可迁移 auth、storage 和后端数据模型的团队。

Android 游戏开发者需要哪些工具？

多数游戏团队从 Unity、Godot 或 Unreal 开始，再添加崩溃报告、分析、广告、支付、云测试和多商店发布。

Android 应用应该发布到哪些商店？

全球分发通常从 Google Play 开始，并根据用户考虑 Samsung Galaxy Store、Amazon Appstore、Huawei AppGallery 或 F-Droid。中国大陆分发需要规划华为、小米、OPPO、vivo、荣耀、腾讯应用宝等渠道。

ADB Pro 会上传 Web Navigation 或 Logs 数据吗？

不会。Web Navigation 只是从 IDE 打开开发资源。Logs 是本地操作记录，不会自动上传，只有你手动导出或提交时才会共享。
