IDE 内的免费 AAB 转 APKS 工作流

Android App Bundle 是发布产物，不是像 APK 一样可以直接安装到设备的文件。本地测试通常需要 bundletool、签名配置、APKS 输出文件、连接设备，以及匹配设备配置的安装命令。AAB Tools 将这条命令行链路变成聚焦的 JetBrains IDE 工作流。

当连接多台设备时，AAB Tools 可以把一个选中的 bundle 安装到多个选中的在线设备。批量安装使用 Universal APK 模式，因此同一个生成的 APK 可以跨不同设备配置安装；单设备工作流仍然保留用于 split APKS 测试。

这个插件刻意保持免费和聚焦。它解决个人开发者、QA 测试和小项目最常见的 AAB 转换与安装循环。如果流程继续扩展到签名校验、发布检查、R8、资源混淆、CI/CD 和依赖健康，ADB Pro 是主升级路径。

AAB 转 APKS

在 IDE 中执行 bundletool build-apks，从选中的 Android App Bundle 生成可安装的 APKS 归档。

安装到设备

为指定设备执行 split APKS 安装，或选择多个在线设备执行 Universal APK 批量安装。

管理 Bundletool

自动检测、下载和缓存 bundletool.jar，避免依赖手动路径配置。

读取签名配置

在可用时解析 Gradle signingConfigs，也支持手动 keystore 作为兜底。

查找 AAB 文件

扫描常见 Gradle 输出目录和自定义目录，按修改时间和构建类型展示本地 AAB 文件。

扫描远程 Release

连接 GitHub 或 GitLab releases，查找 CI 发布的 AAB assets，私有仓库可通过 token 访问。

AAB Tools 如何工作

  1. 从 Android Studio、IntelliJ IDEA 或 Gradle 构建 Android App Bundle。
  2. 打开 AAB Tools 工具窗口并刷新本地 AAB 列表。
  3. 选择 Gradle 签名配置，或提供手动 keystore 配置。
  4. 让插件管理 bundletool，或使用已配置的 bundletool 路径。
  5. 将选中的 AAB 转换为 APKS 归档。
  6. 选择一个连接设备进行定向安装，或选择多个在线设备进行 Universal APK 批量安装。
  7. 仅在开发场景下使用 force install，例如需要主动替换签名冲突安装包时。

FAQ

AAB Tools 是免费的吗？

是。AAB Tools 是免费的 JetBrains Marketplace 插件，聚焦 AAB 转 APKS 和安装流程。

可以直接把 AAB 安装到 Android 设备吗？

不可以。设备安装的是 APK 或 split APK，不是原始 AAB 文件。AAB Tools 使用 bundletool 生成 APKS 归档，再安装匹配设备的 APK。

可以把一个 AAB 安装到多台连接设备吗？

可以。选择想要安装的在线设备并执行批量安装即可。为了适配不同设备配置，批量安装使用 Universal APK 模式；如果要测试设备专属 split APK，请使用单设备安装。

AAB Tools 会自动下载 bundletool 吗？

会。插件可以自动管理 bundletool.jar，开发者不需要在使用前手动下载和配置路径。

可以读取 Gradle signingConfigs 吗？

可以。AAB Tools 可以解析 Gradle 签名配置，也支持 Gradle 配置不可用或不适用时手动填写 keystore。

支持 GitHub 或 GitLab release 中的 AAB 文件吗？

支持。插件包含 GitHub 和 GitLab 仓库的远程 release 扫描，私有仓库可以通过 token 访问。

AAB Tools 和 ADB Pro 有什么区别？

AAB Tools 免费且聚焦 AAB 转换和安装。ADB Pro 是付费完整发版工作流插件，还包含发布检查、签名工具、R8 Assistant、资源混淆、CI/CD、依赖健康和构建性能等能力。
