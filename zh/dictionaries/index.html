如何使用

下载字典文件后放到 Android 项目中，例如和 proguard-rules.pro 放在一起，然后在 ProGuard 配置中添加对应指令：

proguard-rules.pro
# 应用混淆字典
-obfuscationdictionary proguard-dic-homoglyph.txt
-classobfuscationdictionary proguard-dic-homoglyph.txt
-packageobfuscationdictionary proguard-dic-homoglyph.txt

# 也可以使用 Encoding Chaos 制造跨编码显示差异
-obfuscationdictionary proguard-dic-encoding-chaos.txt

也可以在 ADB Pro 插件的 R8 Assistant → Dictionary 标签页中直接下载、管理并应用这些字典。

关于这些字典

每个字典都包含通过 Character.isJavaIdentifierStart() 校验的 Unicode 字符。这些字符利用不同书写系统之间的视觉相似性，也就是 homoglyph，或者利用同一 UTF-8 字节在不同系统编码下显示差异明显的特性。

例如，Homoglyph 字典包含看起来像拉丁字母的希腊和西里尔字符，比如希腊 alpha α 与拉丁 a。Encoding Chaos 字典则选择在 GBK、Big5 或 Shift-JIS 环境中可能被解释成完全不同字符的内容。

全部 11 个字典都是开放且免费使用的，即使不安装 ADB Pro 插件也可以直接下载。

推荐用法

  • 追求最大混淆：使用 Ultimate 字典，合并全部 3,056 个字符。
  • 追求平衡效果：组合使用 Homoglyph 和 Encoding Chaos。
  • 追求轻量混淆：使用 Minimal Confusable，52 个字符，每个 ASCII 字母一个替代字符。
  • 追求编码环境差异：使用 Encoding Chaos，在 CJK 编码环境中显示差异更明显。

自动化管理混淆字典

ADB Pro 可以在 IDE 内直接下载、应用和管理混淆字典，不需要手动复制和维护文件路径。
