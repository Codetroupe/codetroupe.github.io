Core Module

Signing Tools

Complete APK signing toolkit with v1, v2, and v3 scheme support. Verify signatures, optimize with zipalign, and manage keystores securely — all inside your IDE.

Overview

Signing Tools provides a full-featured APK signing workflow directly within your JetBrains IDE. It supports all three Android signing schemes — v1 (JarSigner), v2 (APK Signature Scheme), and v3 (APK Signature Scheme v3) — and wraps them in a streamlined UI with secure credential management powered by IntelliJ's PasswordSafe API.

Key Capabilities

APK Signing (v1, v2, v3)

Sign APKs using any combination of signing schemes. The v1 JarSigner scheme provides backward compatibility for older devices, while v2 and v3 APK Signature Schemes offer stronger integrity protection and faster verification on modern Android versions. ADB Pro uses Google's apksigner under the hood for v2/v3 signing, ensuring compatibility with the latest Android platform requirements.

Signature Verification

Verify the signature of any APK with a single click. The verification report shows which signing schemes are present, certificate chain details (issuer, subject, validity period, serial number), and whether the signature covers the entire APK contents. Catch signature issues before they reach the Play Store.

Zipalign Optimization

Run zipalign on unsigned or signed APKs to ensure all uncompressed data starts at a 4-byte boundary. Proper alignment reduces RAM usage on device and is a Play Store requirement. ADB Pro automatically detects misaligned APKs and offers one-click alignment.

Keystore Management via PasswordSafe

Store keystore paths, aliases, and passwords securely using IntelliJ's PasswordSafe API. Credentials are encrypted by the IDE and never written to plain-text config files. Switch between multiple keystores (debug, release, enterprise) from a favorites dropdown without re-entering passwords.

Favorite Signing Configs

Save frequently used signing configurations as favorites for instant access. Each favorite stores the keystore path, key alias, signing scheme preferences, and zipalign flag. Perfect for teams managing multiple app variants or signing identities.

Signing Schemes Comparison

Scheme Name Min Android Tool Notes
v1 JarSigner All versions jarsigner / apksigner Legacy scheme; required for pre-7.0 devices
v2 APK Signature Scheme v2 Android 7.0+ apksigner Whole-file signing; faster install verification
v3 APK Signature Scheme v3 Android 9.0+ apksigner Supports key rotation; proof-of-rotation struct

Typical Signing Workflow

Signing an APK with ADB Pro
# 1. Build your unsigned APK
./gradlew assembleRelease

# 2. Open Signing Tools panel in ADB Pro
# 3. Select the APK from build outputs
# 4. Choose a signing config (or create a new one)
# - Select keystore file
# - Enter key alias
# - Choose signing schemes (v1 + v2 recommended)
# 5. Click "Sign" — ADB Pro handles zipalign + apksigner
# 6. Verify the signed APK with one click

Settings

Signing Tools settings are accessible from Settings > Tools > ADB Pro > Signing Tools. You can configure:

  • Default signing scheme selection (v1 only, v2 only, v1+v2, all schemes)
  • Custom apksigner and zipalign binary paths (auto-detected from Android SDK by default)
  • Automatic zipalign before signing (enabled by default)
  • Favorite signing configurations (add, edit, remove)
  • PasswordSafe credential storage preferences

Menu Actions

Signing Tools provides quick-access actions under the Tools > ADB Pro menu:

  • Sign APK... — Open the signing dialog for any APK file
  • Verify APK Signature — Check the signature of the selected APK
  • Zipalign APK — Align the selected APK for optimal performance
  • Manage Keystores... — Open the keystore and favorites manager
