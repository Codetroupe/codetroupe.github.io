Core Module

AAB Tools

The most comprehensive Android App Bundle toolkit inside your IDE. Convert, sign, install, and manage bundles — all from one panel.

Overview

AAB Tools is the flagship module of ADB Pro, designed to eliminate the friction between building your Android app and getting it onto a device. It wraps Google's bundletool with an intuitive UI and adds powerful features like remote repository scanning, secure keystore management, and automated signing workflows.

Key Capabilities

AAB to APKS Conversion

Automatically detects .aab files produced by your Gradle builds and converts them to .apks archives using bundletool. The bundletool binary is downloaded and managed automatically — no manual setup required.

One-Click Install

Install converted APKS directly to any connected device or emulator. ADB Pro handles device detection, ADB path discovery, and installation status reporting.

Signing Configuration

Parse signing configurations from your build.gradle or build.gradle.kts files. Manage keystores and key aliases with favorites. Passwords are stored securely via IntelliJ's PasswordSafe API — never in plain text.

Remote Repository Scanning

Configure GitHub or GitLab repositories to scan for AAB files in release assets. Download remote bundles, convert, and install — useful for QA teams testing release candidates.

File Scanning

Automatically scans your project's build output directories for AAB files. No need to browse file dialogs — the latest build artifacts appear instantly.

Workflow

Typical AAB Tools workflow
# 1. Build your app
./gradlew bundleRelease

# 2. ADB Pro auto-detects the .aab output
# 3. Click "Convert" — bundletool generates .apks
# 4. Select target device
# 5. Click "Install" — done!

Settings

AAB Tools settings are accessible from Settings > Tools > ADB Pro > AAB Tools. You can configure:

  • Custom bundletool path (override auto-managed version)
  • Default signing configuration
  • Remote repository credentials and scan patterns
  • Favorite signing configs for quick access

Menu Actions

AAB Tools also provides quick-access actions under the Tools > ADB Pro menu:

  • Quick Install AAB — Convert and install the most recent build
  • Select and Install AAB... — Choose from all detected AAB files
  • Convert AAB to APKS — Convert without installing
  • Install APKS File... — Install a pre-existing APKS file
