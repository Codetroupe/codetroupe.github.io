Core Module

Build Tools

Streamline Gradle build automation with variant selection, batch builds across flavors, build history tracking, and instant artifact location.

Overview

Build Tools wraps Gradle's command-line interface into a visual panel that understands your Android project structure. Instead of memorizing task names and flavor combinations, pick variants from a dropdown, trigger builds with a click, and find your output artifacts instantly. Build history is tracked locally so you can review past build results without scrolling through terminal output.

Key Capabilities

Gradle Task Execution

Run any Gradle task from the Build Tools panel. Common tasks like assembleDebug, assembleRelease, bundleRelease, and clean are available as one-click buttons. Custom tasks can be entered manually and are saved for reuse. Build output streams to the panel in real time so you can monitor progress without switching to the terminal.

Variant Selection (Debug / Release / Custom)

ADB Pro parses your build.gradle or build.gradle.kts to detect all available build variants, including product flavors and build types. Select the exact variant you need from a dropdown — no more typing assembleFreeRelease by hand. The selected variant persists across sessions, so your last-used configuration is always ready.

Batch Builds Across Flavors

Need to build all flavor combinations at once? Batch mode queues multiple variant builds and runs them sequentially. This is ideal for release managers who need to produce APKs for free/paid variants, multiple ABIs, or white-label builds. Each build result is logged independently with success or failure status.

Build History Tracking

Every build is recorded with its timestamp, variant, duration, exit code, and output artifact path. Review past builds in a sortable table to find which variant was built last, how long it took, or whether it succeeded. History is stored locally in the IDE project settings and never leaves your machine.

Artifact Location

After a successful build, ADB Pro automatically locates the output APK or AAB file and shows its path. Click to reveal the file in your system file manager, copy the path to clipboard, or pass it directly to Signing Tools or AAB Tools for the next step in your release pipeline.

Settings

Build Tools settings are accessible from Settings > Tools > ADB Pro > Build Tools. You can configure:

  • Custom Gradle executable path (default: project Gradle wrapper)
  • Additional Gradle arguments (e.g., --stacktrace, --parallel, -Pci=true)
  • Default build variant on project open
  • Build history retention limit (default: 50 entries)
  • Post-build actions (auto-reveal artifact, notification sound)

Menu Actions

Build Tools provides quick-access actions under the Tools > ADB Pro menu:

  • Build Current Variant — Run assemble for the selected variant
  • Build All Variants — Trigger a batch build of all detected variants
  • Locate Last Artifact — Show the most recent build output in the file manager
  • View Build History — Open the build history table
