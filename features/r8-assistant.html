R8 Assistant

Intelligent code obfuscation made easy. Auto-detect your dependencies, generate correct keep rules, and harden your app with custom obfuscation dictionaries.

Overview

The R8 Assistant takes the guesswork out of ProGuard/R8 configuration. It scans your project's dependencies, identifies libraries that need special keep rules, and generates an optimized proguard-rules.pro file. It also includes reflection risk scanning, mapping file analysis, stack trace deobfuscation, and a library of 11 preset obfuscation dictionaries.

Sub-Features

Rule Recommendation

Scans your build.gradle dependencies and recommends ProGuard/R8 rules from a database of 20+ popular libraries including Retrofit, Gson, Moshi, Room, Hilt, Kotlin Coroutines, and more. Each recommendation includes comments explaining why the rule is needed.

Reflection Risk Scanner

Scans your source code for reflection-based patterns that can break after obfuscation. Detects usages of Class.forName(), getMethod(), getDeclaredField(), and JSON serialization libraries that rely on field name matching.

Mapping File Analysis

Load and analyze mapping.txt files from R8/ProGuard builds. View class and method renaming statistics, identify heavily obfuscated packages, and search for specific class mappings.

Stack Trace Deobfuscation

Paste a stack trace from a production crash and deobfuscate it using your mapping file. Supports both R8 and ProGuard mapping formats. Integrates with remote mapping file storage.

Rule Tester

Validate your ProGuard rules before running a full release build. The rule tester checks for common syntax errors, conflicting rules, and overly broad keep patterns that could inflate your APK size.

Obfuscation Dictionaries

Download and apply preset obfuscation dictionaries that use Unicode confusable characters for maximum code protection. 11 preset dictionaries are available — from visual lookalikes (Greek, Cyrillic) to cross-encoding confusion (characters that display differently in GBK, Big5, Shift-JIS).

Example Output

Generated proguard-rules.pro
# ── ADB Pro R8 Assistant ── Generated Rules ──────────
# Detected: Retrofit 2.9.0, Gson 2.10.1, Room 2.6.0

# Retrofit
-keepattributes Signature, *Annotation*
-keep class retrofit2.** { *; }
-keepclasseswithmembers class * {
    @retrofit2.http.* <methods>;
}

# Gson
-keep class com.google.gson.** { *; }
-keepclassmembers class * {
    @com.google.gson.annotations.SerializedName <fields>;
}

# Obfuscation Dictionary
-obfuscationdictionary proguard-dic-encoding-chaos.txt
