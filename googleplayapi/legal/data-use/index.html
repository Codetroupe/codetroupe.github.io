Effective November 11, 2026 · Covers GooglePlay API 1.0.0 and this documentation website

Codetroupe is the publisher of GooglePlay API and the contact for this policy at 294128852@qq.com. This policy covers the IDE plugin, the documentation website and information you voluntarily send for support. Your generated Android application's privacy practices are your responsibility and are described separately below.

1. Local code generation

The plugin analyzes Android projects and generates code locally. It has no publisher-operated advertising, analytics, crash-upload or project-upload service. Google account sign-in, OAuth tokens and service-account credentials are not required for local Google API template generation.

To identify modules and prepare changes, the plugin can read:

  • Gradle settings and module build files, including namespaces, application IDs and dependency configuration.
  • Android Manifest content and source paths, including Kotlin text used to detect Compose.
  • Existing contents of files targeted by a change plan, for previews and on-disk conflict checks.
  • Names and options you enter, including package, class name, language and update mode.

This project information is not uploaded to the publisher or Google as part of generation. Basic project checks look for selected local files; they do not verify every variant or upload Firebase configuration.

2. Files, temporary state and external actions

Previewing code does not apply a change plan. Selecting Apply Changes writes the reviewed source, guide and supported Gradle changes to your project. Those files remain after the plugin is disabled or uninstalled.

The plugin keeps before/after file snapshots in memory for guarded restoration and IDE Undo/Redo. It checks affected unsaved editor documents and refuses to replace later file changes. Snapshots are not a persistent backup and do not replace version control.

Copy puts the displayed content on the system clipboard. Your operating system and any clipboard-history or synchronization service govern it afterward. Official docs opens an external page in your browser; that site may process normal connection information under its own policy. The plugin does not attach project files or credentials to these documentation links.

IDE logging, local history, caches, backups, Marketplace installation and Gradle dependency downloads are separate IDE, operating-system or build-tool activities.

3. This documentation website

This website's source does not include advertising scripts, analytics scripts, third-party font requests, purchase forms or account sign-in. It stores the theme choice under googleplayapi-theme in your browser's local storage. You can remove that preference through your browser's site-data controls.

Example-code copy buttons use the clipboard only when you select them. Reading a guide does not provide a plugin trial or start an activation process.

This site is hosted on GitHub Pages. GitHub records visitor IP addresses for security purposes independently of this site's scripts. See the GitHub Pages data-collection explanation and GitHub Privacy Statement. External links open services with their own data practices.

4. Marketplace license verification

The distributed plugin uses JetBrains Marketplace licensing. It reads the confirmation stamp and applicable expiration information for its own product from the IDE, then verifies the JetBrains signature locally in the background. A confirmation may contain a license identifier or other signed licensing metadata. The plugin does not request your account password, read your account profile, receive your payment details or operate a separate publisher activation service.

Current confirmation, a credential fingerprint and verification decisions are held temporarily in application memory and shared across project windows. Positive decisions are cached for at most six hours and are bounded by applicable platform or signed-stamp deadlines; unsuccessful decisions have a short cache. Changed or missing evidence, refresh and disposal invalidate the relevant state. The plugin does not persist license payloads or decisions, log verification payloads or exception traces, or forward them or project source to Codetroupe.

Activation, account, purchase, floating-server and offline or fallback entitlement processing belong to the IDE and its licensing services. They may use network connections and follow the JetBrains Privacy Notice and applicable purchase terms. The documentation website does not process payments or receive your license key.

5. Code running in your Android app

The plugin and the Android app you build are different software. Generated code calls Google SDKs after you integrate and build it into your application. Those SDKs' processing is governed by the chosen services, app configuration and your application's disclosures.

  • Play Integrity: send the returned token to your backend for verification. Keep server credentials outside the app.
  • Play Billing: verify purchase tokens and entitlements through a trusted workflow. This is your app's billing integration, separate from the IDE plugin purchase.
  • Firebase Analytics and Crashlytics: decide which events and diagnostics are collected, configure defaults and consent, and provide the app's own privacy information.
  • Updates and review: follow the relevant Play SDK requirements and data-safety guidance. A review callback does not confirm that a rating was submitted.

Firebase may initialize before Application.onCreate. When collection must stay disabled until a choice is resolved, configure defaults before that initialization and then apply stored choices. Adding a generated component alone is not a complete consent system.

References: Firebase privacy, Analytics collection controls, and Crashlytics collection controls.

6. Support and updates to this statement

The plugin has no built-in support-ticket upload. If you contact the publisher or use a linked support service, you choose what to send. Error messages and IDE logs may contain file paths. Remove secrets, personal data and confidential project content before sharing them.

Support correspondence can include your email address, message, plugin and IDE versions, and attachments you choose to provide. It is used to understand and respond to your request. Correspondence may remain in the support mailbox and its backups for handling the request and related follow-up, subject to applicable obligations and the email service's practices. The publisher does not sell support correspondence or use it for advertising.

You can remove the website theme preference through your browser's site-data controls, manage the system clipboard through your operating system, and delete generated files through your own project tools. Disabling or uninstalling the plugin does not delete generated source or cancel a Marketplace subscription. For requests about personal information you sent directly to Codetroupe, including access, correction or deletion, contact the support address; requests are handled according to applicable rights and obligations. Manage JetBrains account information and purchases through JetBrains.

Contact Codetroupe at 294128852@qq.com. Review this statement when accounts, licensing, telemetry, website forms or storage behavior changes. See the support guide for information to include in a report.
