Development builds

These entries describe completed development work. They do not indicate that a paid Marketplace release is available.

0.1.8November 5, 2026

Packaging & verification

  • Added a separate obfuscated plugin package, retaining the IDE entry points and template resources.
  • Verified the packaged code through isolated template and Swing checks, and IDEA / Android Studio compatibility checks.
  • Expanded the product description to make integration responsibilities and current limitations clear.
0.1.7November 4, 2026

A consistent plugin identity

  • Applied the puzzle-and-code identity to the sidebar, Tools menu, panel header and generic component fallback.
  • Added light and dark sidebar variants for compact and standard IDE layouts.
  • Set new default layouts to the lower-left button group with a bottom-docked panel, while respecting saved positions.
0.1.5November 2, 2026

One update feature, two modes

  • Combined Flexible and Immediate updates into a single In-app updates entry.
  • Added an Update mode choice that carries through code, initialization, setup and planned files.
  • Introduced a neutral default component name while preserving customized class names.
